## Repository Structure

Each assignment lives in its own folder. Future assignments will be added following the same `Assignment-n` naming convention:

```
Assignemnts/

├── Assignment-2/   (upcoming)

```

The shared Python dependencies for the repository are listed in [requirements.txt](requirements.txt). Install them once at the repo root.
